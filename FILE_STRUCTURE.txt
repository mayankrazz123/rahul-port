WHAT EACH FILE DOES:
====================

📄 index.html
- Contains all the HTML structure
- All sections: Hero, About, Skills, Portfolio, 3D Viewer, Experience, Contact, Footer
- Edit this to change content, text, and structure

📄 css/style.css
- All visual styling
- Colors, fonts, layouts, animations
- Responsive design for mobile/tablet/desktop
- Edit this to change appearance

📄 js/main.js
- All interactive functionality
- Navigation, scroll effects, portfolio filters
- 3D viewer setup, contact form validation
- Modal system, lazy loading, animations
- Edit this to change behavior

📁 assets/images/
- All image files for the website
- Profile photo, project images, client logos
- Replace placeholder images with your own

📁 assets/models/
- Optional 3D model files for the viewer
- Currently uses basic shapes (cube, sphere, cylinder)
- Add .glb files to load real 3D models

📄 assets/resume.pdf
- Your resume/CV for download
- Linked from the About section


CUSTOMIZATION PRIORITY:
=======================

🔴 MUST CHANGE (Before going live):
1. index.html - Your name, email, bio, social links
2. assets/images/profile.jpg - Your photo
3. assets/images/projects/ - Your project images
4. js/main.js - Project data (titles, descriptions)

🟡 SHOULD CHANGE (For personalization):
5. css/style.css - Colors to match your brand
6. index.html - Skills, experience, achievements
7. assets/resume.pdf - Your actual resume

🟢 OPTIONAL (Advanced):
8. Add real 3D models to assets/models/
9. Integrate contact form with backend
10. Add custom fonts or animations


FILE SIZE RECOMMENDATIONS:
==========================

Profile Photo:        < 200 KB
Project Thumbnails:   < 500 KB each
Project Details:      < 2 MB each
Model Thumbnails:     < 100 KB each
Client Logos:         < 50 KB each
3D Models:            < 10 MB each
Resume PDF:           < 5 MB

Total Website Size:   < 50 MB (without 3D models)


EXTERNAL DEPENDENCIES (CDN):
============================

The website uses these external libraries (loaded from CDN):
- Google Fonts (Inter, Orbitron)
- Font Awesome 6.5.1 (icons)
- Three.js r128 (3D rendering)

These require internet connection to load.
For offline use, download and host locally.
